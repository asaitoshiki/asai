ラップスタア誕生RAPSTAR 2017 – 2026

ABEMAが2017年から続ける、次世代ラッパーを発掘するオーディション番組。応募者は審査員の前で課題をこなし、勝ち残った数人が決勝のステージで1曲を披露して頂点を争います。2024年のシーズンから番組名は「ラップスタア」（RAPSTAR）になりました。
