# 推し活ノート

推し活の記録をひとつにまとめた Web アプリです。カレンダー・チェキ／写真・支出・グッズ・日記・聖地巡礼を
1 つのアプリで管理できます。スマホのブラウザで開いてホーム画面に追加すると、アプリのように使えます（PWA）。

## できること

| 画面 | 内容 |
|---|---|
| ホーム | 次の予定までのカウントダウン、今日の予定、推しカード、今月の支出 |
| カレンダー | 月間カレンダー。日付ごとに予定・写真・支出・日記をまとめて登録／閲覧 |
| フォト | チェキ・写真・グッズ・チケットのギャラリー。推し／種別／お気に入りで絞り込み |
| 支出 | 支出の記録、月ごとの推移・カテゴリ別・推し別の集計 |
| 推し | プロフィール、メンバーカラー、誕生日・推し始めた日、ペンライト（全画面カラー） |
| グッズ | コレクションの種類別管理と点数の集計 |
| 日記 | 気分つきの日記。写真を添付できる |
| 聖地・遠征 | 行った場所の記録 |
| 設定 | テーマ切替、バックアップの書き出し／復元、保存容量、サンプルデータ |

誕生日と「毎年くりかえす」記念日は、毎年のカレンダーに自動で並びます。

## データについて

**データはすべてこの端末のブラウザ（IndexedDB）に保存されます。** サーバーには何も送りません。
ログインは不要ですが、そのぶん次の点に注意してください。

- ブラウザのサイトデータを削除すると、記録も消えます
- 機種変更や別のブラウザへの引き継ぎは、設定画面の **バックアップの書き出し／復元** で行います
- 写真は長辺 1600px に縮小して保存し、一覧用に 400px のサムネイルを別に持ちます

## 開発

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck  # 型チェック
npm run build      # 型チェック + 本番ビルド
```

### 技術構成

- Vite + React 19 + TypeScript
- Tailwind CSS v4
- Dexie（IndexedDB）+ dexie-react-hooks の `useLiveQuery` で、保存すると画面が自動更新される
- React Router（`HashRouter`）— GitHub Pages のサブパス配信でも深いリンクが 404 にならないため
- vite-plugin-pwa

### ディレクトリ

```
src/
├── db/         スキーマ・Dexie インスタンス・クエリ・バックアップ・サンプルデータ
├── lib/        日付／画像／カレンダー展開などの純粋な処理
├── components/ 画面をまたいで使う UI
└── features/   画面ごとの実装（home, calendar, photos, expenses, oshi, goods, diary, places, settings）
```

日付はすべてローカルタイムの `YYYY-MM-DD` 文字列で扱います（`Date` を跨ぐと UTC ずれで前日になるため）。

## デプロイ

`.github/workflows/deploy.yml` が main への push で GitHub Pages に公開します。
このファイルは **リポジトリのルートに置かれたときだけ** 動きます。公開前に
Settings → Pages → Source を「GitHub Actions」にしてください。

サブパス配信に合わせるため、ビルド時に `VITE_BASE`（例: `/oshikatsu-app/`）を渡しています。
