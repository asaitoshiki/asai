# submix

Netflix の字幕を、行ごとに「日本語 / 英語 / 非表示」へ確率的に振り分ける Chrome 拡張機能。

字幕のオン・オフしかない状態を、負荷スライダー1本の連続的なつまみに変える。
行単位で松葉杖の強さを混ぜるのが、既存の類似拡張との唯一の差分。

## 表示レベル

音声は英語である前提。

| レベル | 表示 | ねらい |
|---|---|---|
| L0 | 日本語字幕 | 松葉杖あり。意味は確実に取れる |
| L1 | 英語字幕 | 音声と同じ語が文字で出る。英語のまま処理する |
| L2 | 字幕なし | 素の状態 |

## 振り分け

負荷スライダー（0〜100）から各レベルの出現確率を決める。表の間は線形補間する。
対応表は `src/core/constants.ts` の `LOAD_TABLE` に集約してある。

| 負荷 | L0 | L1 | L2 |
|---|---|---|---|
| 0 | 100% | 0% | 0% |
| 30 | 55% | 40% | 5% |
| 60 | 20% | 55% | 25% |
| 100 | 0% | 45% | 55% |

確率を引いたあと、必ず次の制約で補正する。

- 最初の1行は必ず L0
- L2 は2行までしか連続させない。3行目は L0 か L1 に落とす
- 冒頭が必ず L0 なので、L2 の直前には必ず表示された行（助走）が来る
- 対応付けに失敗した行は無条件で L0

乱数は行インデックスから決定的に引く。同じ動画・同じ負荷なら再生し直しても
同じ振り分けになる。振り分けを変えるのはポップアップの「混ぜ直す」だけ。

## フォールバック

聞き取れなかったら `d` キーを押す。その行を**一段だけ**下げ、行頭の少し手前まで
巻き戻して再生し直す。

- L2 の行 → L1（英語字幕を出す）
- L1 の行 → L0（日本語を出す）

下げた行は記録され、ポップアップから見られる。「混ぜ直す」で記録した上書きは消える。

## 構成

```
src/
  core/       純粋ロジック。DOM も Chrome API も触らない（テスト対象）
    constants.ts  負荷→確率の表と各種閾値。調整はここだけで完結する
    parse.ts      TTML(imsc1/dfxp) と WebVTT のパーサ
    align.ts      日英キューの対応付けと失敗検出
    levels.ts     レベルの振り分けと制約補正
    rng.ts        シード文字列から決定的に引く乱数
  page/       MAIN world。マニフェストのフックと字幕トラックの取得
  content/    ISOLATED world。プレイヤー DOM、オーバーレイ、フォールバック
  popup/      設定 UI
```

### 字幕トラックの取得

Netflix のプレイヤーマニフェストは復号後に必ず `JSON.parse` を通るので、
MAIN world で `JSON.parse` を差し替えて `timedtexttracks` を捕まえる。
`XMLHttpRequest.open` も保険として見張る。

字幕本体の fetch はページコンテキスト（MAIN world）で行う。字幕 CDN
（`nflxvideo.net`）を `host_permissions` に足さずに済ませるため。

### 日英の対応付け

日本語字幕は英語字幕の逐語訳ではない。意訳で2行が1行にまとまり、タイミングは
数百ミリ秒ずれる。時間の重なりで連結成分を作り、次のように扱う。

- 1対1で十分に重なる → そのまま対応させる
- 1対多 / 多対1 → 束ねて1つの表示単位にする
- 多対多 / 片側のみ / 重なり比が閾値未満 → 対応付け失敗（その区間は L0 固定）

行の境目の薄い重なりで連結成分が数珠つなぎに育たないよう、辺の条件は秒数と
比率の両方で締めてある（`OVERLAP_MIN_SEC` と `EDGE_OVERLAP_RATIO_MIN`）。

精度を上げるより、失敗を検出して安全側に倒すことを優先する設計。

### 表示

標準字幕は `html[data-submix='on'] .player-timedtext` で隠し、自前のオーバーレイに
描く。プレイヤーの DOM に触るのは `src/content/player.ts` だけで、表示領域が
見つからなければ即座に例外を投げる。

## 保存とプライバシー

- 保存先は `chrome.storage.local` のみ。サーバーは持たない
- 保存するのは設定と、フォールバックした行の記録（直近500件）だけ
- 外部通信は Netflix の字幕トラック取得のみ
- 権限は `storage` と `https://*.netflix.com/*` の `host_permissions` だけ

## 開発

```sh
npm install
npm run build      # dist/ に出力
npm run watch      # 変更を監視してビルド
npm run typecheck
npm run test
```

`chrome://extensions` で開発者モードを有効にし、「パッケージ化されていない拡張機能を
読み込む」から `dist/` を指定する。

### Netflix での確認

対応付けと振り分けのロジックは vitest で固定してあるが、Netflix 実機での確認は
手元で行う必要がある。

1. 英語音声・日本語字幕がある作品を再生し、DevTools のコンソールに
   `[submix] <movieId> の振り分けを開始しました` が出ることを確認する
2. 標準字幕が消え、自前のオーバーレイに字幕が出ることを確認する
3. ポップアップで負荷を動かし、日本語 / 英語 / 非表示の混ざり方が変わることを確認する
4. `d` キーで一段下がり、行頭に巻き戻ることを確認する

`[submix] 字幕トラックを取得できません` が出る場合はマニフェストの構造か
プロファイル名が変わっている。`src/page/hook.ts` の `PROFILE_PREFERENCE` と
`findManifests` を疑う。オーバーレイが出ない場合は `src/content/player.ts` の
セレクタを疑う。
