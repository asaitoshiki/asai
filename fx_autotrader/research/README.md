# 研究メモ

`fx_autotrader` ディレクトリで `PYTHONPATH=. python research/<スクリプト>.py` として実行します。
データは `fetch` / `fetch-history` / `combine` で `data/` に用意しておきます。

## 研究のルール

- たくさん試すほど偶然良く見える手法が出るため、**理由のある手法だけ**を試す
- 期間を分けても、通貨ペアを変えても同じように勝てるかを見る
- 最終確認用に、次の6通貨ペアは手法が決まるまでデータを取らずに封印する:
  NZD/USD、USD/CAD、USD/CHF、CAD/JPY、CHF/JPY、NZD/JPY

## 結果（2026年11月時点）

| 手法 | スクリプト | 結果 |
| --- | --- | --- |
| 1時間足の機械学習 | `fxbot.cli tune` | 予測力は少しあるが、スプレッドとAPI手数料に負ける |
| 日足の機械学習 | `fxbot.cli tune --granularity D` | ずっと買いと変わらない |
| 過去60日の上げ下げに乗る | `momentum_pairs.py` | USD/JPY 以外の6ペアでは再現せず（年率 −3.4%〜+1.7%） |
| 五十日の仲値前の買い（8時/9時→10時） | `gotobi.py` | 2023年以降はむしろマイナス。効果は消えている |
| 五十日の仲値後の売り（10時→15時） | `gotobi.py` | コスト後 +1.4銭/回だが t値 1.25 で偶然と区別できない |
| 7ペア分散の時系列モメンタム | `tsmom.py` | 2004〜2026 年率 +1.1%（シャープ 0.26）、2015年以降ほぼ0、2020年以降マイナス |

## まだ試していない、理由のある手法

- **キャリー（金利差・スワップポイント）**: FXで最もよく知られた収益源。政策金利のデータが必要
- **バリュー（購買力平価）**: 物価との比較で割高・割安を判断する。物価指数のデータが必要
