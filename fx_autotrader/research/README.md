# 研究メモ

`fx_autotrader` ディレクトリで `PYTHONPATH=. python research/<スクリプト>.py` として実行します。
データは `fetch` / `fetch-history` / `combine` で `data/` に用意しておきます。

## 研究のルール

- たくさん試すほど偶然良く見える手法が出るため、**理由のある手法だけ**を試す
- 期間を分けても、通貨ペアを変えても同じように勝てるかを見る
- 最終確認用に、次の6通貨ペアは手法が決まるまでデータを取らずに封印する:
  NZD/USD、USD/CAD、USD/CHF、CAD/JPY、CHF/JPY、NZD/JPY

## 結果（2026年11月時点）

| 手法 | スクリプト | 結果 |
| --- | --- | --- |
| 1時間足の機械学習 | `fxbot.cli tune` | 予測力は少しあるが、スプレッドとAPI手数料に負ける |
| 日足の機械学習 | `fxbot.cli tune --granularity D` | ずっと買いと変わらない |
| 過去60日の上げ下げに乗る | `momentum_pairs.py` | USD/JPY 以外の6ペアでは再現せず（年率 −3.4%〜+1.7%） |
| 五十日の仲値前の買い（8時/9時→10時） | `gotobi.py` | 2023年以降はむしろマイナス。効果は消えている |
| 五十日の仲値後の売り（10時→15時） | `gotobi.py` | コスト後 +1.4銭/回だが t値 1.25 で偶然と区別できない |
| 7ペア分散の時系列モメンタム | `tsmom.py` | 2004〜2026 年率 +1.1%（シャープ 0.26）、2015年以降ほぼ0、2020年以降マイナス |
| キャリー（金利の高い方を買う、7ペア分散） | `carry.py 0.005 research` | 年率 +0.9%（シャープ 0.18）、2008年 −16%。2004〜2014はほぼ0 |
| キャリー＋流れのフィルター（7ペア分散） | `carry.py 0.005 research` | 年率 +0.9%（シャープ 0.27）、前半・後半とも安定、最大下落 −10% |
| **同上を封印していた6ペアで最終確認** | `carry.py 0.005 sealed` | **年率 −0.4%（シャープ −0.10）、2015年以降は年率 −1.5%。再現せず** |

金利は FRED の各国3か月金利（月次、1か月遅らせて使用）を `data/fred/` に保存して使います
（`https://fred.stlouisfed.org/graph/fredgraph.csv?id=<系列ID>`）。スワップは金利差から業者の取り分（年0.5%）を引いて近似しています。

最終確認用の6ペアは、キャリー＋流れのフィルターの検証で開封済みです。以降の検証に「まだ見ていない通貨ペア」はもう残っていません。

### 後から気づいた傾向（未検証）

キャリーは、研究用・最終確認用のどちらでも「高金利通貨を買って円を売る」ペア（AUD/JPY、GBP/JPY、NZD/JPY、CAD/JPY）で
年率 +2.8%〜+3.9% とプラスでした。ただし結果を見たあとで気づいた傾向で、確かめるための未使用データが残っていないため、
有効とは判断していません。2008年のような円高局面では大きく負ける性質の手法です。

## 暗号資産（2026年11月時点）

`crypto_trend.py`。価格は FRED のコインベース日次終値（`CBBTCUSD` など、USD建て）と Twelve Data の XRP/USD。
コストは片道0.1%、現金部分の金利は0、買いのみ（空売りなし）。研究用は BTC・ETH の〜2020年、確認は 2021年〜と、
封印していた LTC・BCH・XRP。手法は研究期間の結果を見る前に次の2つに決めた。

- **流れに乗る**: 過去20・60・120日の値動きの向きの平均がプラスなら全額保有、そうでなければ現金
- **流れに乗る＋値動き調整**: 上に加え、直近30日の値動き（年率）が40%を超える分だけ保有量を減らす

| コイン（期間） | ずっと持つ（シャープ / 最大下落） | 流れに乗る＋値動き調整（シャープ / 最大下落） |
| --- | --- | --- |
| BTC 研究期間 〜2020 | 1.55 / −84% | 1.83 / −44% |
| ETH 研究期間 〜2020 | 1.32 / −94% | 1.95 / −30% |
| BTC 確認 2021〜 | 0.57 / −77% | 0.91 / −36% |
| ETH 確認 2021〜 | 0.63 / −79% | 0.93 / −30% |
| LTC 封印・全期間 | 0.74 / −94% | 0.74 / −60% |
| BCH 封印・全期間 | 0.25 / −98% | 0.49 / −44% |
| XRP 封印・全期間 | 0.53 / −83% | 0.50 / −61% |

**最大下落はすべてのコイン・期間でずっと持つ場合の半分〜2/3程度に抑えられた**（最終確認まで再現した初めての性質）。
一方、シャープレシオ（安定度）が上回ったのは BTC・ETH・BCH で、LTC は同等、XRP はわずかに下回ったため、
「より多く稼げる」とまでは言えない。値動き調整なしの「流れに乗る」は XRP で −93% まで下落し、再現しなかった。
